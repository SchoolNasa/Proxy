# Como usar:

1 - Abra o PolyMC;

2 - Clique nas configurações;

3 - Clique na aba proxy;

4 - Selecione SOCKS5;

5 - Cole o ip 150.136.234.139 e a porta 1080;

6 - Baixe a sua versão do Mine;

# Para conectar a servidores (Proxy no Mine)

1 - Abra as configurações;

2 - Vá na aba java;

3 - Cole "-DsocksProxyHost=150.136.234.139 -DsocksProxyPort=1080" no java arguments;

4 - Seja feliz (se funcionar);
